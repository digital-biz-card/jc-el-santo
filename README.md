# JC El Santo

Independent interactive artist card concept. Original supplied portrait, custom record sleeve layout, working external music links, accessible song selection, vCard and dedicated Instagram QR page. No audio is hosted or autoplayed.

Original phone is unverified. Original email was incomplete and is deliberately excluded. Music destinations sourced from the artist's Linktree and linked Apple Music artist page, 1 November 2026.

QR payload: https://www.instagram.com/jcelsanto/

Static HTML/CSS/JS, no build required. GitHub Pages main/root.
